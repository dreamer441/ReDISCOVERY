# Git safety

Inspect git status before substantial changes and preserve user modifications.
Never run git reset --hard, git clean -fd, force pushes, or history rewrites.
Review git diff and untracked files before reporting completion.
Commits and pushes of reviewed in-scope work are authorized (owner, 19 Oct 2026). Never force push or rewrite history.
Do not stage unrelated files or generated Unreal output.
